# L4D2 Visual VScript v0.7.1 — 槽位、变量模板与分区拖动修复

本版以 v0.7 为基础，仅修复下述问题，没有重构积木类别或修改 .l4vp 文件头格式。

## 1. 官方圆形方法块拖不到变量定义的 value

- 新增画布视口级 `ExpressionSlot` 命中测试：即使指针停在槽位内部的 `QLineEdit` 上，也能识别外层 value 槽。
- 将 `QGraphicsProxyWidget` 中可能失去投递对象的 Drop 事件优先转发到命中的值槽；场景原来的分区拖放保持不变。
- 支持官方方法/自定义调用、圆形变量引用、已存在的可返回值积木进入表达式槽。
- void 方法、控制流积木不可占据返回值槽；拖入后更新真实的 AST 数据，并保留递归生成 Squirrel 的能力。
- 修复递归嵌套官方方法参数时，内部适配器不是 QWidget 却被用作父控件的问题。

## 2. 普通 / Table / Set 类型切换时编辑模板未更新

- 切换到普通时显示普通值槽；切换到 Table 时给出 `{}`，切换到 Set 时给出 `[]`。
- 数据定义工作区操作按钮会随选择即时出现或消失，更新通过下一个事件循环进行，避免在 QComboBox 信号执行过程中销毁控件。
- 类型之间的初始化表达式有独立缓存；返回普通类型时支持恢复原有嵌套方法表达式。
- 若已打开过复杂变量定义区，转换为普通类型后代码生成器不会继续错误输出原 Table/Set 的定义。
- 如果再次选择 Table/Set，可继续使用原来与变量 ID 关联的独立数据工作区，容器结构同步到新类型。

## 3. 分区拖动速度与手势不一致

- 鼠标拖动标题统一采用 `global -> viewport -> scene` 两点差计算位移，缩放到 50%/200% 后仍与指针移动对应。
- 触屏标题拖动改为实际的画布 scene 坐标差，不再将屏幕像素简单除以缩放系数。
- 增删积木、类型变更仅重建所需控件，不主动改变任何分区的 model.x/y。

## 验证

- 44 项不依赖 PySide6 的自动化测试通过。
- `compileall` 通过；已有 Juggernaut `.l4vp` 示例成功解析，能生成 122 行 `.nut`。
- `tools/gui_smoke.py` 新增真实控件层的 value 命中、官方方法嵌入和类型切换校验（请在已安装 PySide6 的 Windows 环境运行）。
- **当前执行环境无法安装 PySide6，GUI 和实际触控设备尚未实测。** 这三项应在你的机器上做一次手动确认。
