# v0.9.9.7 — 自适应积木高度和显示偏好

## 修复：自动换行后被裁切

- 参数标签与对应输入槽放到同一个不可拆分的布局单元，避免标签落在上一行、槽位落在下一行。
- 积木使用具备明确高度的字段容器，不再假设所有参数始终只有一行。
- 每次积木宽度变化后，根据实际可用宽度计算换行数量和最低高度；高度更新会向外层 If/Else / Event 分区传播。
- `flow_geometry.py` 使用同一套换行规则生成布局坐标和计算总高度，防止布局绘制了第二行，但父容器仍分配单行高度。
- 多层嵌套表达式整体换行，不将表达式内部的变量输入强行拆开。极长的单个嵌入表达式仍可能需要横向滚动。

## 新增：设置 → 语言与模块风格

- 语言：简体中文 / English。
- 模块风格：一般（按用途描述）/ 专业（保留原方法与事件标识）。
- 中文一般风格：如 `GetActiveWeapon` 显示为「获取当前持有的武器」，`weapon_reload` 显示为「当玩家开始换弹时」。
- English 一般风格：如 `Get active weapon` / `When weapon reload happens`。
- 方法参数在一般风格使用更易读的标签；中文、英文的一般风格对方法接收者和操作名称采用不同排列。
- 积木工具库中的官方方法、事件预览也会一起更新，搜索仍支持原名称。
- 设置持久化在本机 Qt `QSettings`，不会写入 `.l4vp`；切换后刷新已有工作区，原有 ID、变量值、嵌套结构及导出的 `.nut` 完全不变。

### 说明

- 大量官方方法/事件的通俗标签使用保守的名称词元拆分；没有经过核实的中文释义仍保留原 API 名称，避免伪造官方说明。已核对的常见方法/事件提供了针对性的中文释义。
- 工程管理和部分进阶弹窗仍存在尚未翻译的文字，不声称覆盖了全部 643 个方法及全部事件的人工中英文语义注释。
- GUI 在 Windows / PySide6 下尚未做鼠标布局实机测试；自动化测试主要覆盖换行几何、标签、模式隔离及代码生成。
