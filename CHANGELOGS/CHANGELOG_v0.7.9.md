# v0.7.9 — 工程树、运算积木及离线官方参考导入

- 工程树：修正新建 nut 后的目录刷新，支持工程根右键新建文件/文件夹、文件和文件夹重命名、删除；重命名同步调整 IncludeScript 依赖；嵌套目录导出时自动创建目录。
- 工程树拖拽：子目录中的文件使用完整的相对路径，而非只传递文件名。
- Scratch 式运算：算术、比较、逻辑和位运算积木，可作为表达式嵌入；Math 函数积木和文档中的标准数学函数。
- 使用用户提供的 Valve `Script Functions` 网页转存文档导入 629 条函数记录；方法库总计 643 条，包含以前遗漏的类和全局/Math/Strings 方法。官方原文说明、签名和参数类型出现在悬停提示中。
- 使用用户提供的 L4D2 事件资料转存导入 285 个事件条目，260 个有明确字段列表；`env` 成员窗口自动显示这些字段、字段类型和逐字段说明。没有数据的事件仍显示未知，并允许手动成员输入，不编造字段。
- 所有数据以 `resources/official_functions.json`、`resources/official_events.json` 随 ZIP 离线分发；工程不会运行时联网。
- `Global/Globals/Math/Strings` 的可拖动方法生成直接的 `function(...)` 调用，而非错误的 `Math.function(...)`。
- 修正嵌套的运算和数学表达式插槽。
- 83 项非 GUI 单元测试通过。未运行 Windows PySide6 UI，也未运行游戏内 Squirrel 验证。

## 来源限制
转存页面中的部分事件确实没有参数，有的只记录名字而没有具体说明；函数的特定重载或不完整签名不能从文本自动恢复。解析出的内容以源文本为准，请结合游戏内 `script_help` 对具体引擎版本再次验证。`official_*` 数据 JSON 为附属文档资料，非运行时代码执行依赖。
