# v0.8.2

- 复制 Table / Set 变量时，连同 Data 子定义分区及嵌套成员独立复制（沿用并校验 v0.8.1 逻辑）；可在复制的变量圆圈右键打开成员窗口。
- 成员选择窗口提供“● 根变量”、“使用当前层”、“× 返回上一层”。例如从 env.userid 可重新选 env 或其他字段；原始声明不受影响。
- 变量圆圈双击重命名；工程栏双击文件或普通文件夹重命名，右键重命名仍可使用（沿用 v0.8.1）。
- 普通函数调用和对象方法的参数均采用 ExpressionSlot。进一步将 NetProps.property、Summon.classname 改为可拖入变量的表达式槽；保留普通文字时其原有字符串语义。
- 代码生成器对动态 NetProps 属性名和动态 Summon classname 正确产生表达式，不再将嵌入引用序列化为 Python dict 字符串。
- 修复直接变量引用 (`variable_ref`) 在双击重命名原变量时不更新路径的问题；支持简单直接成员路径。
- 非 GUI 自动化测试 92 项通过。

限制：复杂变量嵌套表达式/重命名路径中的所有多级引用尚未构成完整语义依赖图；Windows Qt GUI 实际鼠标拖放测试未执行。
