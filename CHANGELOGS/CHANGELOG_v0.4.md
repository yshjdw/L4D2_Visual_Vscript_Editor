# v0.4 — 仅实现两项指定的画布改动

1. **已有积木拖动、移动及磁吸插入（语句层）**：在每块左上角 `⠿` 把手拖动；拖至其他块上半部分插到它前面、下半部分插到它后面；拖到 C 形空白分支区域插入分支末尾。支持跨分区移动，Ctrl+拖动复制整棵积木。维持事件区、数据定义区规则，禁止循环嵌套到自己。所有位置更新到原 AST，保存 `.l4vp` 后保持。
2. **随内容自适应宽度**：输入框实时按输入文本变宽（单槽暂设上限 620px），外层积木、C 形分支及分区随布局重新计算宽度，取消分区原来的 770px 宽度封顶。

**不做**：表达式块插槽嵌套、布尔块连接、新型函数返回值拖入接口。原有表达式文本框保持不变。

交互说明：用积木左侧 `⠿` 拖动整个积木，而不是拖动正在编辑的输入框。分区依旧拖标题；滚轮/触屏缩放方式不变。

限制：磁吸目前通过所指块上下半区决定前后插入位置；不是 Scratch 的凸凹轮廓动画。运行环境未安装 PySide6，无法进行真实窗口和触屏设备测试。
