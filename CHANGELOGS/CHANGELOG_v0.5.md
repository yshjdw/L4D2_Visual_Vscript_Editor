# v0.5 — 积木形状工具库及平移修复

- 左侧工具库由文字树改为真实可视积木形状预览：按照类别分组，颜色与工作区一致；If/While/For/Foreach/Try/Event 显示 C 形包裹区域。
- 可在工具库中直接拖动任意积木，拖出时有彩色图形跟随，松开后在工作区创建。
- 支持在工具库搜索积木。
- 修复 Qt.SpaceModifier 不存在导致的鼠标按下崩溃；改用 Key_Space 按下/释放跟踪空格 + 左键平移，保留鼠标中键平移。
- 没有添加表达式积木嵌套。

注：此环境缺少 PySide6，未能进行实际 GUI 运行和触摸测试；Python 语法与核心单元测试已执行。
