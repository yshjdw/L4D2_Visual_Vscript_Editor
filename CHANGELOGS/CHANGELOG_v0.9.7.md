# v0.9.7 — ScriptScope 引用库与跨窗口拖放修复

1. 修复 ScriptScope 声明位于 If / Else / 循环等嵌套分支时，`find_source` 不递归查找导致成员库空白的错误。
2. 修复 ScriptScope 绑定实体由变量积木（variable_ref 表达式）提供时，比较绑定字符串错误的问题。
3. ScriptScope 成员引用库移到复杂变量编辑窗口的底部，采用可横向滚动的独立面板，不再占用左侧积木工具栏位置。
4. 成员引用库只展示其他相同实体绑定的 ScriptScope 数据分区中已经定义且非 `reference` 的成员，避免自身重复引用。
5. 从成员库跨窗口拖入，或者直接把另一个 ScriptScope 编辑窗口中已定义成员的积木把手拖入当前数据分区，都会创建 `init_mode=reference` 的引用副本；源定义保留原地。
6. 编辑任何已打开的数据分区后，刷新其他打开窗口的成员引用面板。
7. 变量引用路径查找支持嵌套分支内的原始变量声明。
8. 新增嵌套 ScriptScope、变量积木实体绑定、跨窗口引用等回归测试。现共 134 项非 GUI 测试通过。

注意：同实体绑定基于表达式一致性判定；不同表达式即便运行时指向同一实体，也不能自动判定为共享状态。未在 Windows PySide6 GUI 和实际 L4D2 游戏中实测。
