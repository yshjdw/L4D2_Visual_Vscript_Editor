# v0.3 画布改造

- 积木参数直接在工作区编辑（QLineEdit/QComboBox），不再为每个新积木弹出 BlockEditor。
- If/Else、While、数值 For、实体 For、Foreach、Try/Catch、事件分支以嵌套容器可视展示；可直接从左侧工具库拖入分支内部。
- 黄色圆形变量令牌：右键改名、左键拖出复制引用，放到输入框中。
- 复杂变量上的按钮打开专用定义分区。
- Grab：抓住分区标题移动；鼠标中键或空格+左键抓取移动画布。
- Zoom：Ctrl+滚轮和 Qt PinchGesture 双指缩放，限制至 25%~300%。
- AST、数据库、`.l4vp` 存储格式和 `.nut` 代码生成器均沿用 v0.2。

## 已知不足

- 当前是初版原生 PySide6 可视积木，而不是完整 Scratch 磁吸编辑器：不支持把工作区已有块抓起直接转移到别的分支；不支持表达式子积木的任意拼接、连线及在槽中渲染表达式块。
- 复杂字段编辑仍以文字输入为主；少数高级选项/分区属性仍使用对话框。
- 由于运行环境没有 PySide6，本次只能进行静态编译和无 UI 单元测试；需要在 Windows 实测 GUI、拖放和触屏手势。
