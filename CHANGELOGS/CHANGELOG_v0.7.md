# L4D2 Visual VScript v0.7 — 画布与槽位重构

- **分区坐标锁定**：分区 scene origin 只允许通过拖动标题（含触屏标题拖动）修改。增加积木、编辑参数、尺寸扩展或刷新场景均不能改变已有分区坐标；移动积木不再 `board.load()` 全场清屏。
- **工程区快速删除**：工作区已有积木拖动到工程树或积木工具库底部红色删除区即可移除；在拖拽结束后定点刷新。工具库新积木不会当作删除对象。
- **嵌套表达式插槽**：支持将有返回值的官方方法、可返回的自定义调用、表达式及 NetProps Get 直接拖进浅色参数槽；不能放入 void 方法和 C 形流程积木。嵌套后输出值以椭圆展示，布尔返回值以六边形展示；可在槽内继续嵌套下一层。被移动的表达式从原语句位置移除，Ctrl 拖动复制。
- **官方方法不同参数槽**：工具库按 SQLite 方法签名填充 `parameter_specs`；对象槽在方法左侧，参数显示名称/类型，返回值创建可重命名的圆形变量。官方方法名编辑完成后重新匹配签名。独立执行时可在输出变量右键移除结果变量。
- **拖动对象置顶**：抓取分区标题时提升其 Z 值；抓取积木时提升所属分区，并使用 Qt 顶层拖动预览。
- **工作区异常修复**：移除移动积木造成的整场景清空和重建；槽位 drop/积木 drop 在事件结束后刷新；复杂变量可从函数/Think/事件区进入独立数据工作区，并避免非法分区尝试弹出遮挡画布的 QMessageBox。

## 已知限制

- 当前运行容器无法安装 PySide6（无网络），无法在 Windows 触控设备中执行 GUI 烟雾测试。必须由用户实机检查触控坐标、子控件 dropEvent 与 Qt 弹窗表现。
- 离线 SQLite 方法数据库仅是有限子集；对缺少签名或特殊可变参数的 API 允许高级手动输入。不会自行推断未收录参数。
- 输入槽中的嵌套积木以面板/椭圆/六边形表达式形状展示，非 Scratch 的全套像素级拼合轮廓。
