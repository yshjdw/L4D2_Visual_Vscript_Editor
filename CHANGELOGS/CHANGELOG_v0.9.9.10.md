# v0.9.9.10 — Squirrel 代码高度与英语界面修复

## 1. 原始 Squirrel 编辑框按内容自动伸缩

- 去掉原有的 `390px` 高度上限；不再以滚动条掩盖超出高度的脚本内容。
- 按手动换行 `\n` 和长行自动折行计算可见行数；保留末尾的空行。
- 编辑中添加、删除代码会重新计算 QPlainTextEdit 高度，并通知 `WrappingFields`、C 形分支及 `SectionItem` 刷新几何尺寸。
- 高度计算抽取到无 Qt 依赖的 `l4visual/raw_editor_geometry.py`，便于回归测试。

## 2. 扩展 English 界面覆盖

- 新增 `l4visual/ui/localization.py`，统一维护静态控件翻译，支持中/英切换恢复，避免修改用户代码。
- 覆盖了更大范围的菜单按钮、Data/ScriptScope 工作区、成员选择、NetProp 选择、Function 编辑、工具库、占位提示、上下文菜单、对话框标题及常用验证信息。
- 数据绑定型下拉项在切换语言时只改变显示文字，内部仍保存原值；`container_type`、`scope` 下拉框也以这种方式显示英文选项。
- `method_tooltip`、`event_tooltip`、事件 `env` 工具提示在英语模式下显示英文说明，优先使用用户提供的英文官方资料。
- 一般/专业模式及语言偏好均保留；生成 `.nut` 的 API 名称和 AST 不变。

## 3. 验证

- 219 项非 GUI 自动化测试通过。
- 新增代码行数及自动折行计数、缩小、高度取消封顶、英文控件文字、事件提示、静态诊断显示和代码生成不变性回归测试。
- 当前执行环境无法安装 PySide6（网络不可用），因此 Windows GUI 的实际重排和多窗口翻译尚待实机验证。
