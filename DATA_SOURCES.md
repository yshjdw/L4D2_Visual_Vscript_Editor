# API 与 NetProps 离线索引说明

此数据库是为了使原型离线可用而整理的**初版子集**，并非 Valve 完整权威 API 数据库。

主要参考链接：

- L4D2 游戏事件与字段：[AlliedModders — Left 4 Dead 2 Events](https://wiki.alliedmods.net/Left_4_Dead_2_Events)
- Source 共用事件：[Game Events (Source)](https://wiki.alliedmods.net/Game_Events_(Source))
- L4D2 VScript API：[L4D2node VScript](https://vscript.l4d2node.org/)
- NetProps / SendTables：[L4D2node NetProps](https://netprops.l4d2node.org/)
- Valve Developer Community：[L4D2 Script Functions](https://developer.valvesoftware.com/wiki/Left_4_Dead_2/Scripting/Script_Functions)

2026-10-21 的数据库内容统计：**286 条事件名称、150 条方法记录、39 个 SendTable、100 条属性记录**。上述内容包含人工整理及来源参考资料，字段/schema 收录远少于完整事件数量；具体数据请以 `resources/catalog.sqlite3` 为准。

重建：`python tools/build_catalog.py`。重建器从本工程内置的已整理常量生成 SQLite，**不是在线抓取脚本**。数据库属性可能存在 `int` 表示实体句柄、数组字段类型缺失、继承关系未完全收录等情况。NetProps 的读写还受实体类型、运行状态和引擎机制限制；不能把条目存在当成可安全 Set 的保证。

为了以后扩充，接口层 `l4visual/catalog.py` 提供 `events`、`methods`、`prop_tables`、`props`、`stats` 五种查询，并允许查询继承属性。大型完整资料的批量导入和运行时校验尚未实现。

### Curated model literal paths (v0.9.9.39)
- https://github.com/Stabbath/L4D2-Decompiled/blob/master/Misc%20Stuff/models.txt — stock V/W model filename inventory.
- https://github.com/raziEiL/l4d2_weapons/blob/master/scripting/include/l4d2_weapons.inc — world weapon and melee model lists.
- https://github.com/fbef0102/L4D1_2-Plugins/blob/master/Luxs-Model-Changer/data/LMC_L4D_Model_Data.cfg — survivor/infected model paths.
- https://github.com/zonde306/l4d2sc/blob/master/l4d2_simple_special_spawnner.sp — infected models.
These lists supply string literals only; spawning/model attachment depends on the target entity, precaching and the game installation.
- https://github.com/TyUser/l4d2_ty_saveweapon/blob/main/l4d2_ty_saveweapon_4.sp — first-person melee v_ asset paths.

### Expanded classname, item and model literals (v0.9.9.40)
- Valve L4D2 weapon/item spawn entities and stock melee script names: https://developer.valvesoftware.com/wiki/L4D2_Level_Design/Weapon_and_Item_Spawning
- Stock weapon classname and world models: https://github.com/raziEiL/l4d2_weapons/blob/master/scripting/include/l4d2_weapons.inc
- L4D2 v_models and survivor arm models indexed in source stock model filenames: https://github.com/Stabbath/L4D2-Decompiled/blob/master/Misc%20Stuff/models.txt
- V/W gun pairs (including M60): https://steamcommunity.com/sharedfiles/filedetails/?id=3152369356
- Stock melee V/W pairs: https://github.com/TyUser/l4d2_ty_saveweapon/blob/main/l4d2_ty_saveweapon_4.sp
- The model name lists are static resource references; no guarantee an add-on, outdated game install or runtime CreateEntity call will load every asset without proper precaching. No V/W counterpart is generated by substituting a prefix. `classname` includes common Source entity types, not every class supported by the engine.
