L4D2 Visual VScript — PySide6 积木编辑器 v0.7
=================================================

双击 start_windows.bat
或在项目根目录执行：
    py -3 -m pip install -r requirements.txt
    py -3 app.py

首次建议自检：
    py -3 -m unittest discover -s tests -v
    py -3 tools\gui_smoke.py

操作：
- 分区：只抓住标题移动，其他积木操作不能改变分区位置。
- 拖出积木：左侧彩色积木库 -> 工作区或 C 形积木内部。
- 删除积木：抓住已有积木的 ⠿ 把手，拖到左侧工程树或积木工具库底部红色删除区。
- 槽位嵌套：将返回值积木拖到浅色输入槽；表达式为椭圆，布尔结果为六边形。
- 官方方法：工具库 -> 官方方法 -> 展开所属类，拖入后自动生成参数槽。
- 变量：右键重命名、复制引用；复杂变量打开独立工作区窗口。
- 新建分区：工具栏的“添加分区”。
- 缩放：Ctrl+滚轮或画布顶部缩放按钮，抓取空白画布可平移。

项目：独立 .l4vp 文件；.nut 为导出脚本。
本地 API 数据库：286 个事件名、150 条方法记录、39 张 SendTable、100 条 NetProp 记录（不等于官方全集）。

注意：GUI 和触屏未在当前构建环境实际运行，本机没有 PySide6 且不能联网安装。
35 项非 GUI 回归测试通过；请在 Windows 上运行 tools\gui_smoke.py 验证实际窗口环境。
